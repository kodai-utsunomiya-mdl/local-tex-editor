# Local TeX Editor 0.1.1

フォルダーを開く操作，画面の配置，ファイル一覧，原稿の検索を改善した．

## 変更点

- Windows のフォルダー選択画面を更新した．再度「参照」を押すと，開いている選択画面へ戻れる．
- アプリ上部の操作を 1 列にまとめ，原稿と PDF を表示する高さを増やした．
- PDF の下部に常時表示していた操作案内を削除した．各ボタンの説明はマウスを置くと表示される．
- 左側の一覧からフォルダーを展開し，画像や PDF をタブで確認できるようにした．
- 起動画面を，プロジェクトを開く操作と最近開いた一覧を中心とした表示に変更した．
- 検索欄と置換欄で複数行を貼り付けられるようにした．TeX の `\` は入力どおりに検索・置換する．`Ctrl + Enter` で欄の中に改行を入力できる．
- 原稿上の `Ctrl + ホイール` とピンチ操作で文字を拡大・縮小できるようにした．設定と共通の文字サイズを使い，8〜40 px の範囲で変更できる．
- 文字サイズなど表示の設定だけを変更した際に，PDF の更新を促す案内が出る不具合を修正した．
- OneDrive の cloud placeholder を一覧や読み込みから除外する条件を修正した．
- SyncTeX が見つからない場合に必要な操作を README に追加した．
- 設定画面から，スタートメニューやデスクトップへ起動用のショートカットを作れるようにした．アプリをユーザーのアプリフォルダーへ配置するので，ダウンロード先を探さずに起動できる．
- 保存や草稿の記録を終えてアプリを終了した後，ブラウザのタブを閉じるようにした．ブラウザがタブを残す場合は，終了したことと `Ctrl + W` の操作を表示する．
- 別ファイルの読み込み中に終了確認を開いて取り消した際，元の原稿に戻ると入力できなくなる不具合を修正した．

## 更新する

1. 現在のアプリを画面の「終了」で閉じる．
2. `local-tex-editor-0.1.1-windows-x64.zip` をダウンロードして展開する．
3. `local-tex-editor.exe` を起動する．設定と草稿は前回のものを読み込む．
4. 「設定」→「起動用のショートカット」から，次回の起動に使うショートカットを作成できる．

SmartScreen の画面が出た場合は，このリリースから取得したアプリであることを確認し，「詳細情報」→「実行」を選ぶ．

SyncTeX が不足している場合の追加手順は，README の「SyncTeX を追加する」を参照する．
