# Local TeX Editor 0.1.0

Windows のブラウザで原稿を編集し，PC にある TeX Live でコンパイルする初版．

## 起動する

1. `local-tex-editor-0.1.0-windows-x64.zip` をダウンロードして展開する．
2. `local-tex-editor.exe` をダブルクリックする．
3. ブラウザで原稿のフォルダーを開く．
4. 必要に応じて TeX Live の場所 (`C:\texlive\2025\bin\windows` など) とメイン文書を設定する．
5. コンパイルボタンを押す．

Python，Node.js，Go の追加インストールは不要である．TeX Live と `latexmk` は PC にあるものを利用する．

## 利用できる機能

- `.tex` と `.bib` などの編集，タブの切り替え，検索・置換
- 節や小節のアウトラインと，見出しから原稿への移動
- 引用キー・相互参照・TeX コマンドの補完
- 自動保存，草稿の確認と復元，前回の作業箇所からの再開
- ライト／ダークの切り替え
- 原稿にある `latexmkrc` の利用
- upLaTeX，pdfLaTeX，XeLaTeX，LuaLaTeX の選択
- コンパイルのログと終了コードの表示，実行中の停止
- PDF の連続スクロール，倍率ボタン，Ctrl + ホイールとピンチによる拡大縮小
- PDF 内の文字検索，文字の選択とコピー，ダウンロード
- SyncTeX による PDF のダブルクリックから原稿への移動
- 原稿の Ctrl + クリックと「PDF の位置へ」ボタンから PDF への移動
- 再コンパイルと次回のアプリ起動後に，同じ PDF のページ付近を表示
- ログに表示したエラーのファイルと行から原稿への移動
- ファイルが他のアプリで変更された場合の確認

Windows 上で，日本語の原稿，参考文献，実際の TeX の実行，ブラウザでの PDF の表示を確認したビルドを配布する．
