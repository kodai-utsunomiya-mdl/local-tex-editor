# Local TeX Editor 0.1.2

## 修正した内容

- 原稿から PDF へ移動した際に `viewport.convertToViewportRectangle is not a function` と表示される不具合を修正した．PDF.js の現行 API で座標を変換し，移動先を強調表示する．
- ボタンと原稿の `Ctrl + クリック` の両方について，移動直後の強調表示とエラーの有無をテストするようにした．ページの回転と倍率を変えた場合も，実際に描画された図形と強調枠の位置を確認する．
- Windows の実行ファイル，スタートメニューやデスクトップのショートカット，ブラウザのタブに専用の TeX アイコンを設定した．
- ショートカットの作成ボタンをもう一度押すと，既存のショートカットのアイコンも更新されるようにした．

## 更新する手順

1. 現在のアプリを右上の「終了」で閉じる．
2. `local-tex-editor-0.1.2-windows-x64.zip` をダウンロードして展開する．
3. 展開したフォルダーの `local-tex-editor.exe` を起動する．
4. 「設定」→「起動用のショートカット」で，使用している「スタートメニューに追加」または「デスクトップに作成」をもう一度押す．配置済みのアプリと，そのショートカットのアイコンが更新される．両方に作成済みの場合は，両方のボタンを押す．

設定，原稿，草稿，前回の PDF は，引き続き同じ保存先から読み込む．使用中の TeX Live と SyncTeX はそのまま利用できる．
