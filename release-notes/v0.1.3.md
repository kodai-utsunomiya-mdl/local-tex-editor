# Local TeX Editor 0.1.3

## 修正した内容

- 最後の編集タブを閉じると，約 5 秒後にアプリとコンパイル中の処理が終了する．ページの再読み込みで接続が戻った場合や，ほかの編集タブが開いている場合は動作を続ける．
- 異なるバージョンが動いている状態で新しい `.exe` を開くと，起動中の版と今回の版を表示する．原稿を保存して旧版を終了した後に，新しいアプリを起動する．
- 新版の起動時に，ショートカット用に配置したアプリと作成済みのショートカットを更新する．次回も同じショートカットから新版を開ける．
- 設定画面にアプリのバージョンと，動いている `.exe` の絶対パスを表示する．
- タブを閉じる直前の草稿を，小さな変更として PC へ送信する．長い原稿の本文・更新日時・カーソル位置を扱い，通常の保存と終了直前の保存が前後しても新しい内容を書き込む．
- README の冒頭に，原稿と PDF を並べた実際の画面を掲載した．

## 更新する手順

1. `local-tex-editor-0.1.3-windows-x64.zip` をダウンロードして展開する．
2. 展開したフォルダーの `local-tex-editor.exe` を起動する．
3. 旧版が動いている場合は，表示された案内から旧版の編集画面を開き，原稿を保存する．旧版を通常の終了操作で閉じるか，保存を確認して移行画面から旧版を終了する．
4. 新しい編集画面の右下が `v0.1.3` になっていることを確認する．

ショートカットの作成を以前に行っている場合は，その配置先も起動時に更新される．更新に失敗した際は画面に案内が出るので，設定からショートカットを再作成する．

設定，原稿，草稿，前回の PDF は，引き続き同じ保存先から読み込む．使用中の TeX Live と SyncTeX はそのまま利用できる．
